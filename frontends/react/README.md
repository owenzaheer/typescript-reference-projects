# React workflow interface

Start a TypeScript/NestJS API on port 8000. From this folder: `pnpm install --frozen-lockfile`, `pnpm dev`; open the Vite address shown in the terminal. `pnpm build` produces the bundle. Requests are proxied to the local service, so no external account or backend URL is configured in the client. The API project configuration determines the visible workflows. Forms, role selection, status announcements and audit inspection operate the real API.
